# Homebrew Tap

Homebrew formulae for [p3bot](https://github.com/p3bot) tools.

## Installation

```bash
brew tap p3bot/tap
brew install p3bot/tap/start
brew install p3bot/tap/agentdex
```

## Formulae

- [agentdex](https://github.com/p3bot/agentdex) - Detect AI coding agents installed on the local machine
- [start](https://github.com/p3bot/start) - AI agent CLI orchestrator built on CUE
